Box Model e Display

No CSS, todo elemento HTML é tratado como uma caixa. O Box Model define como essas caixas são dimensionadas e espaçadas.

O Box Model é formado por quatro camadas: content (conteúdo), padding (espaço interno), border (borda) e margin (espaço externo).

Demonstração Visual

O quadro abaixo mostra as camadas do Box Model na prática:

margin (laranja — espaço externo)

padding (verde — espaço interno)

conteúdo (content)

Propriedades do Box Model

Propriedade O que faz Exemplo no CSS
width Define a largura do conteúdo width: 300px;
height Define a altura do conteúdo height: 200px;
padding Espaço interno (entre conteúdo e borda) padding: 16px;
border Linha ao redor do elemento border: 2px solid #000;
margin Espaço externo (entre elementos) margin: 20px auto;

Display: Block vs Inline

Elementos block ocupam toda a largura disponível e sempre começam em uma nova linha. Elementos inline ficam lado a lado, ocupando apenas o espaço necessário.
